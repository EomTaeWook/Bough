# Bough

**Bough는 병합 충돌을 더 명확하게 이해하고 해결하기 위한 macOS·Windows용 Git GUI입니다.**

일상적인 Git 작업은 가볍고 빠르게 처리하고, 병합 충돌에서는 변경의 맥락과 선택 결과를 쉽게 파악할 수 있는 경험을 지향합니다.

## 왜 Bough인가요?

기존 Git GUI의 충돌 해결 화면에서는 다음과 같은 불편함이 있습니다.

- 충돌한 양쪽 변경이 어디에서 왔는지 직관적으로 알기 어렵습니다.
- 어떤 변경을 선택해야 할지 판단하는 데 필요한 맥락이 부족합니다.
- 선택한 내용이 최종 파일에 어떻게 반영되는지 즉시 확인하기 어렵습니다.
- 여러 저장소가 상단 탭에 쌓이는 방식은 현재 위치를 파악하고 저장소를 전환하기 불편합니다.

Bough는 충돌한 변경의 출처를 분명히 표시하고, 사용자가 선택한 결과를 최종 파일 미리보기에서 바로 확인할 수 있도록 설계합니다.

## 핵심 경험

- **명확한 변경 출처**: 브랜치, 커밋 등 각 변경이 만들어진 배경을 구분해 표시합니다.
- **읽기 쉬운 충돌 비교**: 충돌 구간과 주변 코드를 함께 보여 주어 판단에 필요한 맥락을 제공합니다.
- **즉각적인 결과 미리보기**: 선택한 변경이 최종 파일에 반영되는 모습을 실시간으로 확인합니다.
- **안전한 충돌 해결**: 결과를 검토한 뒤 파일에 반영하고 Git 작업을 이어갈 수 있도록 합니다.
- **명확한 저장소 탐색**: 상단 탭에 의존하지 않고 현재 저장소와 작업 맥락을 쉽게 파악하고 전환할 수 있도록 합니다.

## 첫 번째 개발 범위

초기 버전은 완전한 Git 클라이언트보다 **충돌 해결 기능**에 집중합니다.

1. 충돌이 발생한 저장소와 파일 감지
2. 충돌 구간 및 양쪽 변경의 출처 표시
3. 변경 선택과 직접 편집
4. 최종 결과 실시간 미리보기
5. 해결된 파일 저장 및 Git 인덱스 반영

현재 읽기 전용 커밋 히스토리 탐색을 추가했습니다. 이후 커밋 작성, 브랜치 조작, 일반 파일 스테이징 등 일상적인 Git 작업을 점진적으로 추가할 예정입니다.

확장 화면과 작업 흐름은 [Design 기획 문서](Design/README.md)에 정리했습니다.

## 기술 방향

- **언어**: C# / .NET
- **플랫폼**: macOS, Windows
- **UI**: Avalonia

현재 프로젝트는 초기 개발 단계입니다. 충돌 파일 탐색, 양쪽 변경 선택, 최종 결과 편집 및 스테이징과 읽기 전용 커밋 히스토리 화면을 구현 중입니다.

## 실행

.NET 10 SDK와 Git이 필요합니다.

```powershell
dotnet run --project Bough.App/Bough.App.csproj
```

왼쪽에서 저장소를 추가하면 해결되지 않은 충돌 파일을 표시합니다. 충돌 구간별로 변경을 선택하고 최종 파일을 확인하거나 직접 편집한 뒤 **저장하고 스테이징**을 누릅니다. 현재 텍스트 충돌은 UTF-8 파일을 대상으로 합니다.

상단의 **History**를 누르면 모든 로컬·원격 참조의 커밋을 브랜치 그래프로 볼 수 있습니다. 커밋을 선택하면 작성자, 날짜, 메시지와 변경 파일이 오른쪽에 표시됩니다. 처음 200개를 표시하며 **Load more commits**로 이전 기록을 이어서 볼 수 있습니다. 이 화면에서는 저장소를 변경하지 않습니다.

## 데이터 생성

`Excel/String.xlsx`가 문자열 원본이며 `Datas/String.json`과 `DataContainer/Generated`는 생성물입니다. 변환기는 각 실행 파일이 있는 폴더에서 실행합니다.

`JsonToCSharp.exe`는 Git LFS로 관리합니다. 처음 저장소를 받은 뒤 실행 파일이 내려오지 않았다면 Git LFS를 설치하고 저장소 루트에서 `git lfs pull`을 실행하세요.

```powershell
cd ExportTools/ExcelToJson
./ExcelToJson.exe --no-pause
cd ../JsonToCSharp
./JsonToCSharp.exe --no-pause
```

현재 포함된 변환기 버전은 파일을 생성한 뒤에도 `Console.ReadKey` 예외와 함께 종료될 수 있습니다. 이 경우 완료 문구와 산출물을 함께 확인해야 합니다. 화면 문구는 `StringTemplate`에서 읽으며, 운영체제 UI 언어가 한국어면 한국어, 그 외에는 영어를 사용합니다.

## 라이선스 방향

개인 및 회사 업무에서의 사용은 허용하되, Bough 자체를 복제하거나 이름만 바꾸어 판매하는 행위는 제한하는 라이선스를 지향합니다.

구체적인 라이선스 조건은 아직 확정되지 않았습니다. 정식 라이선스 파일이 추가되기 전까지는 별도의 사용·복제·배포 권한이 부여된 것으로 간주하지 않습니다.
